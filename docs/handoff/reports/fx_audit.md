# 技能动作 / 特效盘点（fx5，2026-11-13）

> 依据：`show2.ts`（presentPlay ③ / impact / enemyAct / playerHit / beat 各 case）、`bestiary/battle.ts`、`bestiary/heroPose.ts`、`fx/fx.ts`、`docs/GAME_DESIGN.md` v4.3、`rows_v4.ts`。
> 「现状」是改之前的构建（dist/fx5 基线）实测；「改成」是本轮的目标，`✅` = 本轮已做（见 `fx_report.md`），`⏳` = 需要改出手那一拍以外的编排，本轮只备好函数、写明接线位置。

## 0. 改之前的总问题

1. **所有技能共用一个出手**：`presentPlay` ③ 只有一句 `hero.attack(dist)`。狂战、刺客一律冲到目标面前做「劈 / 双刺」，魔导一律「举手推出 + 一颗绿色光球」。技能名、档位、单体 / 群体、元素都不影响动作和特效。
2. **铁壁（防御）是进攻动画**：散骰选「铁壁」时，狂战照样冲上去劈一斧（录像 1.0～2.0 秒英雄跑到食尸鬼面前），护甲 +6 的字还跟着冲出去的人飘在敌人头上。用户直接指出的问题。
3. **群体技能只打一个人**：顺劈斩 4+、血战 5/6、冰环、陨石 5、影舞……英雄只冲向当前目标，其他敌人「莫名其妙」掉血，因果不可读。
4. **命中都长一样**：`impact()` 只有一个 `fxImpact`（米黄 / 群体金黄），没有元素、没有路径（闪电跳、溢出转移、陨石下落）。
5. **控制状态没有身体表现**：冻结只在加状态那一下冒一团冰屑；眩晕 `fxStatus` 里根本没有 `stun` 分支，只有一个「晕」字。
