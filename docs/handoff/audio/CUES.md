# 《六面史诗 3D》音频清单（CUES）

> 生成：音效 = Stable Audio 3 small-sfx（`GameProtos\sfx\gen_v2.py`，规格 `sfx\cues_dicehero_v2.json`）；
> 语音 = Breeze TTS 2（`GameProtos\voice\gen_dicehero_v2.py`，规格 `voice\lines_dicehero_v2.json`）。本文件由 `sfx\make_cues_md.py` 从两份规格生成，改清单请改规格再重跑。

**总原则（用户原话）：不要和弦 / 叮咚小旋律这类乐音音效。** 界面和奖励音一律用非乐音的质感声（敲击、摩擦、金属、石头、布料、风声），不要 do-mi-sol 式上行音阶。
生成方式：短促的声音用「一段多次录音 → 自动切片」（每个 cue 2～3 个种子，切出的候选池里挑）；较长的声音（类型「长单发」）提示词写单个事件、片长≈目标时长，每个种子出一个候选。解码器用 SAME-L（SAME-S 在持续的声音上会带 172 Hz 的帧率嗡声和整串泛音，听起来像有音高）。
生成后自动做「乐音感」检查：严格非乐音（界面类）出现持续音高就扣分；不许旋律（奖励、法术）出现两个以上稳定音高就扣分，候选按分数挑。

实装提示：
- 每个 cue 播放时随机挑一个已选候选，音高 ±4%～8%、音量 ±10% 抖动。
- **连续触发（数金币、数点数、滑条）不能逐次升高音高**，只做随机抖动，否则就成了音阶。现在 `audio.ts` 的 `count` 用 `rate: 1 + count * 0.07` 逐个升调，实装时要改掉。
- 命中类按「冲击 + 材质 + 尾音」分层：`swing`（前奏）→ 技能本体 → `hit_light/mid/heavy/crit`（按伤害分级）→ 状态（`st_*`）。
- 格式：单声道 MP3 64 kbps（和现有 `src/assets/audio/*.mp3` 一致），响度统一到约 −16 LUFS、峰值 ≤ −1 dBFS，首尾静音已裁。
