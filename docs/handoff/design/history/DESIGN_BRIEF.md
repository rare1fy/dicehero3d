# 六面史诗 3D · 规则 v2 设计简报（设计讨论用）

你是被拉来一起做设计的游戏设计师。用户是这个游戏的作者（游戏策划），2D 原版是他自己做的骰子肉鸽。现在 3D 版要把核心规则改成 v2。请用中文写你的方案。

## 一、已经定下来的（用户拍板，不要推翻）

1. **点数是技能的发动机，构筑的是角色技能**。没有骰子库、骰袋、弃骰，也没有骰子构筑。
2. **每回合基础 3 颗骰子**。下回合**临时**变成 4～6 颗，只能来自本回合的出牌结果和职业机制，下回合用完就清零。**禁止任何永久增加每回合抽骰数的奖励**。用户原话：「3 颗骰子和 4 到 6 颗骰子玩起来就是两个游戏」，挣骰子要有连招感和爽感。
3. **骰面 = 点数 + 职业花色**，照桌游《王权骰铸》（Dice Throne）：花色由点数决定，每个职业自己一套。暂定：
   - 狂战：1～3 斧，4～5 血，6 怒（3/2/1）。
   - 魔导：1～2 星，3～4 月，5 日，6 虚空（2/2/1/1）。
   - 刺客：1 毒，2～4 刃，5～6 影（稀有花色放在小点数上）。
   花色和数字都要一眼可识别。
4. **牌型 / 花色组合本身没有任何效果**，只是技能的发动条件（钥匙）。之前「顺子自带群体伤害」这类设计全部拿掉。效果全部来自技能。
5. **出牌只交出满足技能条件的那几颗骰子**，伤害只算这几颗的点数和。剩下的骰子交给职业机制：狂战回合结束消散；魔导吟唱保留到下回合；刺客用于第二次出手。狂战的普攻（任意 1～3 颗）可以多选，作为兜底。
6. **技能伤害和点数挂钩**：伤害 = 交出骰子的点数和 × 技能系数（先试）。
7. **重投**：默认 1 次免费，职业机制照原版保留（狂战卖血重投）。
8. **没有防御骰**（用户：「又臭又长」）。
9. **特殊骰只临时出现**：要么留在场上直到用掉，要么在一到几回合内把所有骰子换掉。来源是技能、职业机制和高级奖励。
10. **用户最喜欢、最有记忆点的是三个职业的特殊机制**，要保留并放大：
    - 狂战：卖血重投（血怒叠伤害）；斩首（直接打死敌人）或完防（护甲完全挡住攻击），下回合各 +1 颗骰；骰子溢出 6 颗时每颗 +10% 伤害。
    - 魔导：星界吟唱，不出的骰子保留到下回合（上限 3→4→5→6 递增）；吟唱回合有奥术屏障；吟唱时受击叠法术反噬（2^N 易伤）；攒满可以超载。
    - 刺客：每回合出手 2 次，第 2 次 +20%，两次同牌型再 +25%；连击产出暗影残骰，可以保留到下回合。
11. **UI**：下回合的骰子以 3D 模型漂浮在 UI 层，有几颗就是几颗；掷出时飞进场景。心形血瓶、技能石牌、结束回合按钮都是 UI 层的 3D 模型。尽量少文字，用图形表达。

## 二、主 agent 已经提的技能设计原则（可以挑战，但要给理由）

- 每个技能都必须有倍率以外的东西：范围（单体 / 弹射 / 全体）、状态（流血、中毒、灼烧、冻结、眩晕、易伤、虚弱）、防守（护甲、屏障、闪避、吸血）、节奏（下回合 +骰、本回合额外出手、生成特殊骰、斩杀）。
- 大牌型（4 颗以上）的意义是「质变」：全体、控制、产出骰子和出手次数、终极技只有大牌型能打出来。小牌型只打单体、上状态、做防守。大牌型技能经常产出骰子，形成滚雪球的连招。
- 每个职业都要有群体技，风格不同：狂战是物理横扫加眩晕，刺客是多段加中毒扩散，魔导是元素覆盖。
- 终极技照《王权骰铸》给一个通用特权（比如无视护甲、不可被闪避或格挡）。

## 三、用户这次的新要求

1. **每个职业至少两个流派**，这样才有构筑的乐趣。
2. **原版已经做过很多骰子效果，要提炼、组合进技能**，不要从零发明。
3. **构筑要想清楚**：升级过的技能被替换掉，之前花的资源是不是白费了？怎么升级？
4. **打怪要爆金币**，要有获得感。看看要不要把经验值也拿过来。
