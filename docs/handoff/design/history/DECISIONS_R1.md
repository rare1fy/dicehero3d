# 主设计师对 Codex 第一轮批评的裁决（据此把 SPEC_v2.md 改成 SPEC_v2.1.md）

Codex 的批评在 `codex_r1_out.md`。以下是我的裁决，合稿时照此修改；没提到的部分保持原样。

## 采纳
1. **每块碑先有一句「动作逻辑」，所有行服务这句话**。照 Codex 的六个问题改写每块碑的一句话：
   - 战意：这回合挡住谁，能把下一回合养大？
   - 处刑：先杀谁，才能把溢出伤害和斩首接起来？
   - 元素：先施加哪种元素，才能让下一段吟唱和释放更值？
   - 数理：现在释放已有形状，还是保留半成品追更大的形状？
   - 影袭：把多少资源变成影，换即时收割还是下一回合的连续行动？
   - 连环刺：怎样用第一刀改点，让第二刀完成原本不存在的组合？
   碑里如果有某一行回答不了这个问题，就删掉或换掉。
2. **行数**：狂战起步 3 行、最多 5 行；魔导、刺客起步 **2 行**、最多 **4 行**。
3. **档位**：取消全局「稀有花色自动提前一档」，改为逐行设计；也不强求每行都有五档。保留一条设计标准，同时作为给玩家的唯一口诀：**「4 颗以上，行动方式会变」**（变成打一片、控制，或者挣骰子 / 加出手）。UI 上每行显示的是这一行实际的档位效果，而不是通用五档。每行最多 3～4 档。
4. **魔导**：
   - 起手就给一个**独立定义效果的混色兑现行**（例：至少 4 颗、其中至少两种花色各 2 颗；把满足整体条件的杂色一起交掉；自己写伤害和元素效果，不调用其他行）。
   - 星辰骰改成 **2、2、4、5、6、6**（即 星、星、月、日、虚空、虚空），保留星面；重算各流派收益。
   - 反噬写死口径：N 从**本次吟唱周期开始**累计，出手（释放）后清零；当前这一击**不**吃自己新增的层数；层数上限 30；UI 显示「再吟唱一回合预计多承受多少伤害」。
5. **刺客**：
   - 精准连击拆成两件事：**伤害奖励**（两刀同一行即 +25%，原版规则）与**产残骰条件**（后一刀比前一刀多用骰子）分开判定。
   - 点数流（连环刺）删掉「收刀 + 隔回合冷却」，改为 Codex 的「飞刀起手标记」：第一刀（飞刀，1 颗）指定一个要完成的形状（顺子或同点），第二刀完成这个形状且投入更多骰子时，产 1 颗暗影残骰。
   - 「所有招式必须 1 颗起发」不作为通用规则，只要求每块碑起步至少有一行 1 颗可发。
   - 影舞不放进起步，改为后续奖励。
   - 刺客的群体行用绝对颗数，不因稀有花色提前。
6. **遗物**：今晚的原型**禁用**极简主义、磨刀石、层厅征服者，以及「每次出手回血 / 产钱」类遗物。所有遗物按**整次出手**触发，不按每段。原型商店只放 4～6 件已经核算过的遗物（每件要写清楚对狂战 1 次出手、刺客 2 次出手、魔导多回合蓄力的收益）。
7. **经济**：取消开局 50 金；击杀是主要收入，打法奖励只做小幅加成；经济遗物和召唤物的奖励每场设上限；溢出产钱统一结算、共用上限；金币到账不等待动画（动画只是表现）。商店价格对齐实际收入（例如特价遗物 42、行强化 50、血瓶 35）。
8. **待辩论 8.x 的表态**全部按 Codex 的表格执行：8.1 第三种方案（即上面第 4 条）；8.2 刺客用绝对颗数；8.3 见第 2 条；8.4 三块变体碑今晚不做；8.5 易伤 ×1.5 作为测试起点；8.6 先保证天赋候选对当前流派有效（无效候选不出现），再谈数量；8.7 保留稀有连斩。8.8 的六条也按 Codex 的表态。
9. **跨波规则**：杀掉上一波最后一个敌人挣到的骰子，在下一波第一回合兑现，并且要有明显的演出（骰子飞进准备区后跟着进入下一波）。
10. **验证指标按构筑阶段拆分**：初始构筑和成型构筑分开定目标（初始构筑不要求 5～6 颗回合）。

## 部分采纳 / 主设计师坚持的
- **一次出手只打一行**：坚持，三个职业统一（Codex 也同意）。
- **经验 → 技能碑，精英 / 首领 → 天赋，金币 → 商店**：坚持（Codex 同意），但按新分工重算成长速度。
- **版本 A**：设计文档里保留（用户要求对比），引擎用同一套「行」数据能表达；今晚原型只做版本 B。
- **点数和**作为某些行的发动条件保留（Codex 第三种方案），与「颗数决定档位」并存。

## 原型范围（新增一节，写进 SPEC_v2.1 的最前面）
- 三个职业各一块代表碑：**战意**（狂战）、**星界元素**（魔导，含混色兑现行）、**影袭**（刺客）。另外三块碑（处刑、数理、连环刺）数据写全，但原型可以晚一步接入。
- 基础 3 骰、1 次免费重投、真实消耗骰子、各职业留骰规则；三职业机制全部做。
- 每职业至少一个可达的 4 骰质变效果。
- 一次技能强化选择（升级时三选一）、一次有效的职业天赋选择（精英后）。
- 怪物爆金币、钱袋累计、一次商店消费（精英之后）。
- UI 清楚显示「这次会花掉哪些骰」「下回合确定得到几颗」。
- 三场战斗：普通（两波：1 只，再 2 只同时在场）→ 精英（精英 + 1 只随从）→ 商店 → 首领（枯骨巫妖，限次召唤，召唤物奖励设本场上限）。
- 砍掉：A 版切换、完整地图、营火改修、外借行、全套 III 级进化、变体碑、完整天赋池和遗物池、污染骰等复杂负面。
