# 主设计师对 Codex 第三轮核验的裁决（v2.2 定稿补丁）

Codex 第三轮在 `codex_r3_out.md`。六条缺口**全部采纳，照它给的改法写死**：

1. **跨波带哪些骰**（1.1、1.9、2.3、第 6 节）：先按职业规则完成回合末留存，只把合法留骰和下回合奖励账本带进下一波；没有携带资格的残骰消散。`carryToNextWave` 存筛选后的结果。
2. **元素交汇算档**（1.5、2.2、第 6 节）：元素交汇配置 `tierCount: 'all'`，交出的骰子全部计档；每种花色附不附带效果，另按该花色颗数 ≥2 判断。
3. **日行重复施放的灼烧**（1.7、2.2、第 6 节）：按目标记录灼烧的来源和施放时的出手序号；本次出手结算后，只清掉**此前**日行施加的保留灼烧，本次新挂的保留；普通灼烧仍在回合末熄灭。
4. **魔导剩骰超过保留容量**（1.1、2.2）：出手后由玩家选最多 3 颗剩骰保留（有余韵时 4 颗），保持骰型和点数，其余消散。原型 UI：默认预选点数最高的几颗，玩家点骰子可以换。
5. **过充屏障公式**（2.2、第 6 节）：增加过充回合计数；屏障 = `4 + 2 × (吟唱前环格数 + 此前过充回合数)`；本次屏障算完再加过充计数，出手后清零。
6. **额外星弹**（2.2 星行、1.6）：额外星弹用本次交出星骰的平均点数 + 弹伤，每段按 1.6 取整；所有星弹结算完后统一施加易伤，本次不吃自己新挂的易伤。
