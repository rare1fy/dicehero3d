# R7B 界面视觉任务单（2026-11-13 晚，用户看了第 9～10 版后的原话，优先级从上到下）

先读同目录 `HANDOFF.md`、`UX_V3.md`（§1b、§2、§3、§5b、§6b、§8）、`R6V.md`、`R6_CONTRACT.md`，看 `TARGET_MOCKUP.png` 和 `ux_png/INDEX.md` 列的图。用户截图里的现状：按钮、边框、重投按钮还是矢量风（平滑圆角、渐变），像纸片。

## 用户原话
1. 「我说的 UI 问题，现在哪些组件、边框、重投的按钮，还是矢量版的，没有按像素的方式绘制。」「按钮还是像个纸片。」
2. 「数字的字体怎么还不是高清像素风的字啊。」
3. 「既然是 3D UI，重投和结束回合点了以后就应该要翻转一下嘛，点下去的时候要有按钮按进去的效果嘛，体现出 3D UI 的优势。」
4. 「放大的技能按钮长按不动的时候要出 tips 才行吧，不然一开始看不懂。」
5. 之前就提过的：骰子六面都写数字；方正的像素字（不要纯高清圆滑字）；瞄准箭头照炉石（等距 V 形节、流动）。

## 要做
1. **全部 UI 按高清像素规范重画**（`UX_V3.md` §6b）：重投按钮、结束回合 / 吟唱按钮、技能槽和出牌按钮、血瓶、状态图标、敌人牌、钱袋、遗物底座、数值胶囊、徽章、标签。只走横平竖直或正 45°，平涂 2～4 档明暗，1u 描边、1u 高光，倒角做成 1～2u 的台阶；贴图 nearest 采样；不要渐变和平滑圆角。工程里已有做到一半的 `ui3d/pixelGrid.ts`、`pixDraw.ts`、`pixMesh.ts`、`pixDigits.ts`、`flaskArt.ts`、`hud/pixParts.ts`、`pixIcons.ts`、`pixPlate.ts`、`platePaint.ts`，能用就用。
2. **按钮有厚度**（§5b）：挤出深度 ≥ 宽度 35%，侧面暗两档，UI 层透视下看得见侧面；不能再像纸片。
3. **按下和翻转**：按下时按钮整体下沉半个厚度、侧面变短（按进去）；松开回弹。重投点了以后整块按钮绕横轴翻转一圈（约 0.35 秒，带回弹）；结束回合 / 吟唱点了以后翻面（沙漏或星辰翻到背面再翻回）。出牌按钮出手时同样有按下感。
4. **所有数字和文字换像素字**：血量、伤害飘字、敌人牌、数值胶囊、骰面、状态角标、标签、tips、选职业卡、首领血条。用 Fusion Pixel 12px（OFL，`_ref/px3d/pit_fonts/`）或 `ui3d/pixDigits.ts` 的像素数字；每个字体像素 = 整数个屏幕像素，nearest，1u 深色描边。手机横屏 844×390 下要看得清。
5. **骰子六面都写数字**：`dice/numFace.ts` 接进 `ui3d/suitFace.ts`，侧面不再画点子。
6. **长按出 tips**：长出来的出牌按钮按住不动约 0.4 秒（手指没移动超过 8 px）就弹出技能 tips（技能名、这一档的效果、目标数、附加效果），松手或开始拖动就收起；技能栏里的普通槽长按同样出 tips。tips 也按像素规范画。
7. 炉石式瞄准箭头（`hud/arrow.ts` + `arrowParts.ts` 基本完成）：短 / 长各截一张特写确认。

## 追加（用户后来又说的）
8. 「激活的技能放大的时候技能图标的模型要再放大一些甚至立起来一些，加强立体感。」——出牌按钮长出来时，技能图标的 3D 模型再放大（约 1.3～1.5 倍于现在）、往上抬高并朝镜头立起来（绕横轴转 25～35°，像立在按钮上），投影跟着变；拖拽瞄准时图标朝目标倾斜。
