## 要做
1. **列清单**（先写，写进 `docs\handoff\audio\CUES.md`）：游戏需要的全部声音，按类别分组，每条写：cue 名、用在什么时刻、风格描述、时长、要几个候选。至少覆盖：
   - 界面：按钮按下 / 松开、光标移动、确认、返回、打开 / 关闭暂停、开关拨动、数值调整、不可点、页面切换、存档提示、地图选节点、地图行进。
   - 骰子：摇骰、扔出、落在木地 / 石地、碰撞、选中、取消、重投、牌型成立（非乐音）、升档、骰子飞向英雄、暗影骰生成、怒火骰生成、星辰骰生成。
   - 三职业技能：狂战（劈砍、铁壁上盾、顺劈斩、溢出、盾冲眩晕、血战、卖血、血怒、斩杀再动、完防）；魔导（奥术弹、冰锥、冰环冻结、闪电链、陨石落地、吟唱持续、小咒、释放爆发、屏障、反噬裂开）；刺客（袖箭、背刺、处决、影步、影舞、拔刀 / 刀鞘少一把、末刀、暗影骰补出）。
   - 战斗通用：轻 / 中 / 重命中、暴击、格挡、护甲碎、中毒、灼烧、冻结、眩晕、治疗、击倒、击碎（体素碎块）、尸体沉地。
   - 敌人：食尸鬼（嘶吼、抓击、受击、死亡）、狼人首领（嚎叫、撕咬、受击、死亡）、巫妖（施法、亡灵风暴、骸骨之矛、召唤、受击、死亡）、盾卫嘲讽。
   - 成长和经济：拾取金币（一串金币时不能像音阶）、升级、选卡、遗物触发、商店买入、喝药、营火休息。
   - 环境循环：标题画面夜林氛围、战斗场景氛围（风、虫鸣）。
   - **人物语音（Breeze，中文）**：三个职业各一套短台词（选中、出手、大招、受伤、残血、胜利、死亡、拿到遗物），每条 2～3 句候选；敌人：狼人首领、巫妖补齐（巫妖沿用锁定音色）。台词要短（1～2 秒），有角色感，不要尴尬的中二长句。
2. **生成**：每个音效 3 个候选（重要的 4 个），语音每句 2～3 个音色 / 语气候选。文件放 `C:\Users\liufengyun\Documents\GameProtos\sfx\out_dicehero_v2\`（语音放 `...\voice\out_dicehero_v2\`），统一响度（约 −16 LUFS 量级，峰值不爆）、裁掉首尾静音，转成游戏能用的格式（看 audio.ts 现在加载什么格式）。
