## 用户原话（这一轮的硬要求）
- 「这种清晰度的 UI + 3x 效果还不错，但是 UI 在绘制上缺乏了像素感，我要的是高清，风格上还是要靠一些像素绘制的规范（比如正常的像素内容一个方块 1 个像素，高清的就是 1 个方块 100 个像素）。」
- 「现在的按钮到底是不是 3D 的？是 3D 的话，明显体积感不够，显得太薄了。」
- 「两边空出来太多了。」
- 之前定的：UI 不能像素低清、关键信息要读得清（文字改成高清渲染的像素字，见第 5 条）；复杂度控制在《我的世界：地下城》的水平（克制的深色半透明边框，金色只给当前可操作的东西）；美术铁律：横平竖直的大块，不要斜线阶梯和随机碎点（正 45° 的 1:1 台阶可以）。

## 要做
1. **美术像素格**：新建一个小模块（例如 `ui3d/pixelGrid.ts`）定义 u（1280×720 参考下 3 参考像素，运行时取整到整数屏幕像素），所有 UI 美术（按钮石面、技能槽、重投、结束回合 / 吟唱、血瓶、状态面板和图标、敌人牌、数值胶囊、徽章、档位灯、刀鞘等）都画在这个格子上：只走横平竖直或正 45°，平涂 2～4 档明暗，1u 描边、1u 高光、1～2u 倒角，发光做成阶梯圈。画布贴图要关掉平滑采样（nearest），保证每个美术像素边缘锐利。
2. **按钮体积**：所有按钮类 3D 模型的挤出深度 ≥ 宽度的 35%，侧面比正面暗两档，UI 层透视下侧面至少露出 6u；正面边缘 1～2u 倒角台阶，底下接触投影；按下下沉半个厚度再回弹。技能图标（渲染代理做的 `models3d.ts`）的体素尺寸要和 u 对上。
3. **贴边锚定**：HUD 左手组锚左下、右手组锚右下、血瓶和状态锚底部正中，都相对安全区边缘排（§1b 的边距、拇指位、尺寸不变），不要在中间取一块 16:9。
4. **骰子点数只用一种写法**（用户：「骰子现在也有个问题，怎么点数和数字都同时存在啊」）：现在顶面是大数字、侧面是点子，看起来两套同时存在。改成**六个面都是数字**（和效果图一致，手机上 4 / 5 / 6 一眼分清），数字用方正的像素数字（按 §6b 的格子画），侧面不再画点子。特殊骰的身体色、发光边框保留。骰子代码在 `src/present/dice/**`（归你）。
5. **字体要有棱角**（用户：「现在的字体也是纯高清字体了，没有棱角了，如果不用真像素字，至少要用方正一点的假像素字」）：HUD、敌人牌、tips、飘字、选职业界面的文字和数字统一换成像素字。工程里已有 Fusion Pixel 12px（OFL 开源，`_ref/px3d/pit_fonts/`、`_ref/dicehero_2d/repo/src/assets/fonts/`，`src/present/ui3d/pixfont*` 已经在用它画部分文字）。渲染规则：每个字体像素 = 整数个屏幕像素（大数字 1u，标签可用更小的整数倍），nearest 采样，1u 深色描边；最小字号以手机横屏 844×390 下看得清为准。字体文件约 600KB，能按用到的字裁剪子集最好（小游戏主包有 4MB 上限），做不到就在报告里说明。
6. 引擎 v4.2 起升级等级会到 IV（只有刀鞘用），罗马数字表补上 `'IV'`。
7. 现有行为（长成出牌按钮、档位形态、拖拽箭头、重投环绕、刀鞘、结束回合按钮、点击热区）全部保留，只换画法和体积。
